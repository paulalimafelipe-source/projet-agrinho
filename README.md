# projet-agrinho
📋 Visão Geral do Projeto "Sustentabilidade em Movimento" é uma aplicação interativa desenvolvida com p5.js que combina arte digital, conscientização ambiental e mecânicas lúdicas. O projeto transforma conceitos de sustentabilidade em uma experiência visual envolvente, onde emojis temáticos ganham vida com movimentos fluidos e orgânicos.
